Contributing
============

Thank you for checking out this project!
This repository is a **proof-of-concept (PoC) designed to demonstrate feature scope**
and spark a discussion with the upstream **OpenTelemetry CNCF Project** community. 

Feedback, Bug Reports, and Pull Requests are always welcome.
Please keep them minimal and precise in scope.
Please understand that it may take several days to receive a response.

## Community & Code of Conduct

The project follows the standard [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).
Please be respectful and collaborative.
